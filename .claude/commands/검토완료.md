검토를 마친 의견서 카드를 '검토완료'로 바꾼다. 입력: $ARGUMENTS (카드 ID 하나 이상, 예: O-20261123-01 O-20261116-02 / 수정 지시가 있으면 함께)

어느 기기에서든(사무실 PC·노트북·집 데스크탑) 이 세션에서 실행한다. 집에서 간헐적으로 검토할 때 쓰는 짧은 절차다.
1. 대시보드 https://claude.ai/artifact/BJRE7CdJZCga3DMiZ1FJvf 의 cards.json을 Artifact read(path "cards.json")로 받는다.
2. 지정한 카드가 있는지, refs에 '상태: 검토대기'가 있는지 확인한다. 없으면 그대로 보고하고 멈춘다.
3. 수정 지시가 있으면 그 부분만 고친다(조문을 바꾸면 법제처 MCP로 원문 대조).
4. refs의 '상태: 검토대기.'를 '상태: 검토완료(YYYY-MM-DD, 법무사 확인).'으로 바꾼다. 법무사가 직접 지시한 카드만 바꾸고, 지시 없이 일괄 변경하지 않는다.
5. `node tools/audit.js cards.json` 통과 후 `cards.json`만 같은 URL에 files로 게시한다.
6. 보고: 바꾼 카드 ID와 제목, 남은 검토대기 건수.
